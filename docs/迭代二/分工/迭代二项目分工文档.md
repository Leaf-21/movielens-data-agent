# 迭代二项目分工文档

## 一、项目目标

迭代二在迭代一数据治理 Agent 的基础上，使用迭代一输出的 MovieLens 1M 清洗数据，新增三类分析能力：

1. **分类**：针对一个用户与电影的组合，预测用户在该评分事件中是否会给出不低于 4 分的评分。
2. **聚类**：根据训练期历史观影偏好构建用户画像，将用户划分为可解释的群体。
3. **降维**：压缩用户偏好画像，展示主要变化方向，并比较降维前后聚类质量、信息保留情况和资源开销。

每一类任务都必须实现两种从课程 PPT 中选择的算法，并分别封装为 Agent 可独立调用的工具。分类模型、画像、群体、降维模型与坐标、参数、指标及版本信息需要保留，供迭代三使用。

## 三、共同技术约束

1. **数据源统一**：只能以迭代一清洗数据快照为本轮输入，并记录实际数据版本/校验值、迭代一清洗规则版本和 `T1/T2`。
2. **时间边界统一**：训练数据 `Timestamp <= T1`；验证数据 `T1 < Timestamp <= T2`；测试数据 `Timestamp > T2`。沿用项目已确定的边界，不在本文件中猜测日历日期。
3. **避免数据泄漏**：分类目标事件的 `Rating` 只能用于生成标签和评估，不能用作该事件自身的预测特征；不得把目标事件发生后的数据用于该事件预测。特征预处理器、聚类画像和降维模型的拟合范围必须符合实验方案并记录。
4. **算法要求**：分类、聚类、降维分别实现两种从课程 PPT 中选择的算法。因当前需求附件没有提供 PPT，具体算法名称须由团队核对 PPT 后填写，不得仅凭惯例声称其来自 PPT。
5. **工具调用**：六种算法都须能由 Agent 独立调用。Agent 负责选择工具、传递参数、组织结果与解释；算法工具返回实际计算结果和可追溯元数据。
6. **结果可信**：未知 ID、历史不足、输入无效、模型不存在或评价未完成时，返回明确状态及原因，不以示例数据或推测值填充。
7. **可复现**：保留模型/画像/群体/坐标、算法参数、评价指标、版本、数据切分和运行记录，以便迭代三使用。

## 四、分阶段实施计划

| 阶段 | 主要工作 | 主责 | 阶段完成标准 |
|---|---|---|---|
| 阶段0：接口和算法锁定 | 核对 PPT 算法候选；填写接口字段；明确清洗快照、T1/T2、特征版本 | 全员，B 负责汇总 | 文档 PR 合并；算法名称和来源可追溯；不存在未讨论的字段分歧 |
| 阶段1：数据就绪 | 读取清洗快照；统计训练/验证/测试数据；建立可复用特征和用户画像输入 | A 主责，B/C 复核 | 数据版本一致；时间切分统计完成；无明显目标泄漏 |
| 阶段2：工具独立开发 | A 做分类两算法；B 做聚类两算法；C 做降维两算法和二维输出 | A/B/C | 每种算法可单独执行并输出参数、版本、指标及错误状态 |
| 阶段3：Agent 接入 | 注册六个算法工具；按用户请求路由；支持指定算法或默认双算法对照 | B 主责，A/C 支持 | 三类自然语言请求能到达正确工具；未指定算法时执行对应两种算法 |
| 阶段4：前端联调 | 接入分类、聚类、降维结果；呈现任务状态、结果依据、局限与追问 | C 主责，B 支持 | 前端显示与后端真实返回一致；失败/不可用情况清晰可见 |
| 阶段5：验收与归档 | 运行测试；修复缺陷；冻结模型与结果版本；整理报告和交接资料 | C 牵头，全员 | 验收清单完成；迭代三所需产物可定位、可复现 |

## 五、成员之间的交接

### A → B/C

A 必须提供：
- 清洗数据快照标识、输入路径或数据读取接口、数据校验信息；
- 特征字典和特征版本；
- 分类标签定义及严格的预测时点约束；
- 两个分类工具的输入、输出、模型版本、评价指标和限制；
- 训练/验证/测试样本数以及标签分布统计。

### B → A/C

B 必须提供：
- 六个工具统一注册方式及调用协议；
- 任务 ID、任务状态、错误码和结果查询协议；
- Agent 如何处理“指定一种算法”和“未指定、需双算法对比”的规则；
- 统一结果封装，不改写算法原始评价指标。

### C → A/B

C 必须提供：
- 前端实际使用的字段清单及缺失字段反馈；
- UI 状态展示规则；
- 联调缺陷单和端到端测试结果；
- 报告/图表的路径及版本索引。

## 六、最终交付物

- 六个可由 Agent 独立调用的算法工具（分类两种、聚类两种、降维两种）；
- Agent 工具注册、自然语言任务路由、状态管理和结果查询；
- 分类模型、用户画像、用户群体结果、降维模型和坐标；
- 每类算法的配置、评价指标、比较结果及选型依据；
- 前端分类、聚类、降维页面及二维可视化；
- 统一数据切分和版本记录；
- 测试报告、运行说明、迭代三交接清单。
